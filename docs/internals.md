# Устройство SDK

- `src/api` - C ABI, контексты и screenshot pipeline
- `src/resize` - фильтры, кеш коэффициентов, SIMD и потоки
- `src/codecs` - PNG/JPEG/BMP/QOI/PNM, DEFLATE и палитры
- `src/text` - OCR-подготовка и цветные детали оригинала
- `src/platform` - DXGI/WGC/GDI и заглушка без capture
- `src/automation` - сессии, провайдеры, UIA и изоляция helper
- `src/observe` - результаты, фильтры, OCR и разметка
- `src/analysis`, `src/draw` - изменения кадров и разметка
- `tools` - необязательный CLI и UIA helper; `tests` - C/C++ проверки

Ресайз использует проходы по двум осям и небольшие строковые буферы
Коэффициенты повторных размеров кешируются; SIMD выбирается по возможностям CPU
Alpha обрабатывается с учётом premultiplication и color space

PNG AUTO сохраняет пиксели без потерь. JPEG использует 4:4:4 по умолчанию;
4:2:0 выбирается явно. Декодеры проверяют размеры и целостность входа

`br_shot` кеширует до четырёх capture-сессий. Повторное кодирование пропускается
после точного сравнения пикселей и настроек. Кеш уменьшенного кадра не подтверждает
неизменность мелких деталей оригинала
