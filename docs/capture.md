# Windows capture

Сборка Windows по умолчанию включает захват. Автоматические тесты выполняются отдельно
с `BR_ENABLE_WINDOWS_CAPTURE=OFF`, без чтения или управления рабочим столом

```bash
br windows --filter Chrome
br capture --window "Chrome" -o chrome.png
br capture --window "Firefox" -o firefox.png
br shot --window "Edge" --profile vision -o edge.png --json
br shot --window "Notepad" --width 1280 -o notepad.png --json
```

## Выбор бэкенда

| Бэкенд | Назначение |
|---|---|
| DXGI | Монитор или область одного монитора |
| WGC | Окно, включая GPU-приложения; Windows 10 1903+ |
| GDI | Совместимый путь, в том числе для RDP |
| GDI_SCREEN | Явный снимок видимых пикселей; перекрывающие окна попадут в кадр |
| GDI_PRINT | Явный PrintWindow; результат зависит от приложения |

`auto` выбирает доступный путь. Явный `--backend` не подменяется другим;
фактический бэкенд возвращается в metadata. Свёрнутые, защищённые окна и отключённые
RDP-сессии могут быть недоступны

В C API `BR_TARGET_WINDOW_FULL` снимает полный `GetWindowRect` через PrintWindow,
включая невидимые края. Допустимы `AUTO` и `GDI_PRINT`, client_area должен быть 0
Обычный `BR_TARGET_WINDOW` сохраняет прежнюю геометрию видимой рамки
Явный PrintWindow при ошибке или пустом кадре возвращает ошибку и не читает экран
через BitBlt. Это не гарантирует результат для любого GPU-приложения

## Повторные кадры

В приложении откройте `br_capture` один раз или используйте `br_shot` с кешем сессий
Переиспользуйте процесс и `br_context`; освобождайте изображения и сессии при завершении
`br_shot_cache_clear()` закрывает кеш явно. Не накапливайте очередь устаревших кадров

`br_capture_grab` возвращает последний доступный кадр. `br_capture_next` ждёт изменения
`settle_ms` ждёт тишины в пикселях до заданного лимита, но не подтверждает выполнение
действия приложением. После действия проверяйте ожидаемое состояние

## Координаты

`br_frame_info.image_to_screen` переводит координаты картинки в физические пиксели экрана:

```c
double screen_x, screen_y;
br_transform_point(&info.image_to_screen, image_x, image_y, &screen_x, &screen_y);
```

Применяйте карту один раз. После перемещения окна или изменения состояния старые
координаты нужно перепроверить. Для мелкого текста и иконок храните оригинал и вызывайте
`br_vision_prepare` от него: [vision-detail.md](vision-detail.md)
